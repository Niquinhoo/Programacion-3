# Cierre local de STP2 — 8 de noviembre de 2026

Alcance autorizado: completar lectura offline, Lighthouse, documentación y el
parche compatible de Expo. Implementación y revisión a cargo del agente principal.

## Decisión

Guardar la última lista válida de D1 con Cache API en el servicio existente.
Resolver detalles offline por ID desde esa lista. Evitar una segunda estrategia
de caché en el Service Worker y una cola de escrituras: el alta requiere red.
Los errores HTTP y de autenticación online no deben sustituirse por datos viejos.
Un fallo de almacenamiento no debe hacer fallar una lectura o alta online exitosa.
Avisar cuando se muestra la copia offline y refrescar al recuperar conexión.

## Puntos de revisión

Primera carga sin copia; detalles nunca abiertos; listas vacías; respuesta HTTP
de error o HTML de Access; almacenamiento bloqueado; alta confirmada seguida de
recarga offline; campos conservados al fallar un alta; recuperación de conexión.

La caché es local al perfil/origen y contiene los últimos datos consultados.
Puede quedar desactualizada o ser eliminada por el navegador. Lighthouse local
no acredita el rendimiento de Cloudflare Access, la instalación física ni Expo Go.
No se incluye despliegue, commit o push en este cierre local.
